プライバシーポリシー

Brawl Board（以下「本アプリ」）／最終更新日: 2026年10月17日

かんたんに言うと
  • 広告はなく、利用者を追跡する仕組みもありません。
  • スクリーンショットの解析・持っているキャラの設定はすべて端末の中だけで行い、外へ送りません。
  • 「プロフィール」「チーム募集」「チャット」を使ったときだけ、入力した内容がiCloud の公開データベースに保存され、他の利用者にも見えます。
  • それらは、アプリの「設定 ＞ プロフィールとデータを削除」でいつでも消せます。

1. 本アプリについて

本アプリは、Brawl Stars（Supercell社）のプレイヤー向けの非公式ファンツールです。 ガチバトルの実戦データの閲覧、スクリーンショットからのキャラ提案、プロフィール作成、チーム募集の掲示板を提供します。 Supercell社とは一切関係ありません。開発者は個人です。

2. 取得する情報と使いみち

2-1. 端末の中だけで扱うもの（開発者には届きません）

情報使いみち
写真（スクリーンショット） ドラフト画面の解析、プロフィール画面の文字の読み取り。解析・文字認識は端末内で行い、画像は外部に送信しません。 写真へのアクセスは、利用者が選んだ画像、または「最新のスクリーンショットを解析」を押したときのスクリーンショットだけです。
写真への保存作成したプロフィール画像を保存するときだけ（書き込みのみ。写真の一覧は読みません）。
通知解析結果のお知らせ。端末内で作られるローカル通知です。
持っているキャラ・設定値おすすめから外すキャラや読み上げ設定などを、端末の設定領域に保存します。

2-2. 公開される情報（任意・プロフィール／チーム募集／チャットを使ったとき）

次の内容は Apple の iCloud（CloudKit の公開データベース）に保存され、本アプリの他の利用者が閲覧できます。 使うかどうかは利用者が選べ、使わなければ何も送信されません。

情報内容
プロフィール ブロスタのプレイヤータグ、ゲーム内の名前、アイコン、クラブ名、トロフィー・勝利数・レベルなどの公開プロフィール、 全ブロウラーの状態（パワー・トロフィー等）、ガチバトルの最高ランク／ポイント（画像から読み取った場合）、 ひとこと、フレンド招待リンク、Discord のユーザー名・招待リンク（入力した場合）
チーム募集募集の種類・モード・ランク帯・参加条件・ひとこと・ブロスタのチーム招待リンクまたはチームコード・Discord リンク、投稿時刻
チャット募集ごとのチャットに書いたメッセージ、表示名、アイコン、時刻
識別子iCloud が発行する匿名のユーザー ID（投稿者の判別・ブロック・削除のために使用）。Apple ID のメールアドレスや氏名は取得せず、他の利用者にも見えません。
通報他の利用者を通報したとき、通報理由と対象の投稿・メッセージの内容。不適切な投稿への対応のためだけに開発者が参照します。

パスワード・メールアドレス・電話番号・位置情報・連絡先は取得しません。 プロフィールのひとこと・チャットには、個人を特定できる情報（本名・住所・電話番号など）を書かないでください。

2-3. 外部サービスとの通信

通信先目的・送る内容
GitHub（raw.githubusercontent.com）ゲームの戦略データ（ルールデータ）の取得。個人を特定する情報は含みません。
Brawlify（cdn.brawlify.com）プロフィールアイコンなどの画像の表示。画像の URL が通信先に届きます。
プロフィール取得用の中継サーバー（Vercel） プロフィール作成時に、入力したプレイヤータグを送り、Brawl Stars 公式 API から公開プロフィールを取得します。 中継サーバーはタグや結果を保存しません。ただし Vercel の標準のアクセスログに、通信元 IP アドレスとタグを含む URL が一定期間残ることがあります。
Supercell社の Brawl Stars 公式 API上記の中継サーバー経由で、プレイヤータグに対応する公開プロフィールを取得します。
Apple（iCloud / CloudKit）2-2 の公開情報の保存・取得。Apple のプライバシーポリシーが適用されます。

対戦結果の統計は、開発者が公式 API の公開データを集計したもので、利用者の端末からは何も送信されません。

2-4. 現在提供していない機能

音声で状況を伝える「対話モード」は現在提供していません（画面から利用できません）。将来提供する場合は、 マイクと音声認識の許可を求め、本ポリシーを更新します。許可を求める文言はアプリに残っていますが、現在マイク・音声認識は使用していません。

3. 保存期間と削除

  • チーム募集は投稿から約 20 分で一覧に表示されなくなります。「締め切る」でいつでも削除できます。
  • プロフィール・募集・チャットのメッセージは、アプリの「設定 ＞ プライバシー ＞ プロフィールとデータを削除」（またはプロフィール画面の同じボタン）で、 端末と iCloud の両方から削除できます。
  • アプリを削除すると端末内のデータは消えます。iCloud に残った公開データは、削除ボタンで消してください。 操作できない場合は、下記のお問い合わせから依頼してください。
  • 通報の記録は、不正行為の対応のため必要な期間保存します。

4. 第三者への提供・販売

利用者の情報を、販売したり、広告目的で第三者に提供したりすることはありません。2-3 の外部サービスへの送信は、機能の提供に必要な範囲に限ります。 公開情報は、設計上、本アプリの他の利用者に見えます。

5. 広告・トラッキング

本アプリは広告を表示せず、利用者やデバイスを追跡する仕組み（トラッキング SDK、広告識別子の利用など）を含みません。

6. 利用者が書き込む内容について

プロフィール・募集・チャットは不特定多数の利用者に公開されます。暴言・嫌がらせ・出会い目的・外部への誘導・個人情報の書き込みは禁止です （詳細は利用規約）。不適切な内容は、アプリ内の「通報」「この人を非表示」で報告・遮断でき、 開発者は通報を受けて 24 時間以内を目安に確認・削除します。

7. お子様のプライバシー

本アプリは 13 歳未満の方を対象としていません。公開機能（プロフィール・募集・チャット）は、 保護者の方がご本人の年齢に応じて利用の可否を判断してください。13 歳未満の方の情報を意図して取得することはありません。 お心当たりがある場合は、下記のお問い合わせからご連絡ください。削除いたします。

8. 安全管理

通信は暗号化（HTTPS）されます。保存先は Apple の iCloud で、開発者が独自のサーバーに利用者の情報を保管することはありません。 プロフィール取得用の中継サーバーはタグを保存しません。

9. データの出典

マップ・キャラクターの画像や基礎データは Brawlify の公開 API から取得しています。 ガチバトルのマップ別勝率・キャラ同士の相性は、Supercell社の Brawl Stars 公式 API で公開されている対戦履歴を開発者が集計したものです。 ガジェット・スターパワーの実測勝率は Brawl Time Ninja の公開データを参照しています。 これらは本アプリの開発者が運営するサービスではありません。

10. このポリシーの変更

機能の追加・変更にあわせて更新することがあります。重要な変更があるときは、このページを更新して最終更新日を変えます。

11. お問い合わせ

ご質問・削除のご依頼・不適切な投稿の報告は、GitHub の Issues または サポートページからお願いします。
