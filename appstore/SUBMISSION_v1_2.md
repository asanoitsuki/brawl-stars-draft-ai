# v1.2「Draft Scan」の App Store 文面

1.1 の審査が終わってから、新しいバージョン 1.2 として出す。
**名前・サブタイトル・キーワード・説明文・スクリーンショットに「ブロスタ」「Brawl Stars」とゲームの画像は入れない**（Draft Master と同じ）。
アプリの中では、キャラ・マップの画像を起動後に配信元（Brawlify）から読み込んで表示する（同梱しない）。

## アプリ情報（「アプリ情報」ページ）
- 名前: `Draft Scan`
- サブタイトル: `ドラフトのピックを実戦データで判定`

## プロモーション用テキスト
ドラフト画面のスクショから、BAN と次のピックを判定。背面を 2 回たたくだけで、ゲームを閉じずに結果が通知で届きます。

## 説明文
```
Draft Scan は、3 対 3 のランク戦で行うドラフト（使用禁止・ピック）を手伝う、非公式のファンツールです。

【スクショから判定】
・ドラフト画面のスクリーンショットから、ステージと「いまが BAN の番か、ピックの番か」を読み取ります
・BAN の番なら禁止すべきキャラを、ピックの番なら取るべきキャラを 3 体まで提案します
・提案には、そのステージでの実測の勝率・試合数・使用率をそのまま表示します

【ゲームを閉じずに使える】
・ショートカットと「背面タップ」を設定すれば、iPhone の背面を 2 回たたくだけで撮影から判定まで終わります
・結果は、提案したキャラのアイコンつきの通知で届きます

【データ】
・公開されている対戦記録を毎日集計した、ステージ別の勝率・使用率・キャラ同士の相性を使っています
・持っていないキャラを外して、持っているキャラだけで提案させることもできます

【読めないときは、読めないと言う】
・ドラフト画面だと確認できない画像は解析しません
・ステージ名が読めないときは推測で答えず、自分で選べるようにしています

【プライバシー】
・スクリーンショットの解析は端末内だけで行い、画像を外へ送りません
・アカウント登録・広告・追跡はありません

非公式のファンツールです。Supercell の承認・協賛・提携は受けていません。
利用規約: https://asanoitsuki.github.io/brawl-stars-draft-ai/terms.html
```

## 審査メモ
```
【サインイン】不要です。アカウント作成はありません。

【確認手順】
1. ホームの「写真から選ぶ」（右の画像ボタン）で、ドラフト画面（横向き）のスクリーンショットを選ぶと、ステージと BAN／ピックの番を読み取り、おすすめのキャラを表示します。
2. ドラフト画面ではない画像を選ぶと「ドラフト画面だと確認できませんでした」と表示され、解析しません。
3. 「背面タップで解析できるようにする」で、ショートカットと背面タップの設定手順を確認できます。

【ゲームの画像について】
このアプリは、Brawl Stars（Supercell 社）の非公式・無料のファンツールです。アプリ内で、キャラクターとマップの画像を、Supercell のファンコンテンツポリシー（https://supercell.com/en/fan-content-policy/ ：非営利・非公式であることの明示を条件に、ゲームの素材をファン作品で使うことを認めたもの）に基づいて表示しています。
・画像はアプリに同梱せず、表示するときに配信元から読み込みます
・アプリ名・アイコン・説明文・キーワード・スクリーンショットには、ゲーム名と画像を使っていません
・設定画面に、ポリシーが求める表記「This material is unofficial and is not endorsed by Supercell. For more information see Supercell's Fan Content Policy: www.supercell.com/fan-content-policy.」を載せています
・広告・課金・データ収集はありません

【外部サービス】集計済みの対戦データ（GitHub から取得）、キャラ・マップの画像（Brawlify の配信元から取得）。スクリーンショットの解析は端末内だけで行い、外へ送りません。
```
