お問い合わせ

不具合・ご要望・データ削除の依頼・不適切な投稿の報告は、GitHub の Issues からお願いします（GitHub アカウントが必要です）。

不適切な投稿やチャットは、アプリ内の「通報する」からも報告できます。24 時間以内を目安に確認します。

よくある質問

プロフィールの作り方は？

「チーム募集」または「プロフィール」を開き、①ブロスタの「フレンド招待リンク」を貼る、②プロフィール画面（または Brawl Insights のプロフィール画像）のスクリーンショットを選ぶ、③プレイヤータグを入力、のどれかを行うと、 ブロスタ公式のデータで自動入力されます。名前・トロフィーなどの公式の値は、自分では変更できません。

「ブロスタ公式がメンテナンス中」と出ます

Supercell社の公式 API がメンテナンス中です。終わってからもう一度お試しください。スクリーンショットからも作成できます。

自分のデータを消したい

アプリの「設定 ＞ プライバシー ＞ プロフィールとデータを削除」で、プロフィール・募集・チャットのメッセージを端末と iCloud から削除できます。 iCloud にサインインしていない・通信できない場合は、サインインしてからもう一度お試しください。うまくいかない場合は上記のお問い合わせから依頼してください。

募集に参加ボタンが押せません

募集に「最低トロフィー」「最低ランク」の条件があり、あなたのプロフィールが満たしていない場合は「条件外」と表示されます。

スクリーンショット解析が正しく動きません

ゲームのアップデートで画面のレイアウトが変わると、解析できないことがあります。設定の「枠合わせ」をやり直してください。

通報・ブロックのしかたは？

募集カードの「…」またはチャットのメッセージの長押しから「通報する」「この人を非表示」を選べます。
