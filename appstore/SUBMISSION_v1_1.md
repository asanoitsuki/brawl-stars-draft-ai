# スクショ解析専用版（v1.1）の App Store 文面

チーム募集・プロフィール・チャットを外した版。App Store Connect の各欄にそのまま貼る。

## サブタイトル（30 字まで）
ドラフトのピックを実戦データで判定

## プロモーションテキスト
ドラフト画面のスクショから、BAN と次のピックを判定。背面を 2 回たたくだけで、ゲームを閉じずに結果が通知で届きます。

## 説明文
```
Brawl Board は、ガチバトルのドラフト（使用禁止・ピック）を手伝う非公式のファンツールです。

【スクショから判定】
・ドラフト画面のスクリーンショットから、ステージと「いまが BAN の番か、ピックの番か」を読み取ります
・BAN の番なら禁止すべきキャラを、ピックの番なら取るべきキャラを 3 体まで提案します
・提案には、そのステージでの実測の勝率・試合数・使用率をそのまま表示します

【ゲームを閉じずに使える】
・ショートカットと「背面タップ」を設定すれば、iPhone の背面を 2 回たたくだけで撮影から判定まで終わります
・結果は画面上部の通知で届きます
・アプリ内の手順どおりに進めれば、設定は 1 回で終わります

【データ】
・公式 API の対戦記録を毎日集計した、ステージ別の勝率・使用率・キャラ同士の相性を使っています
・持っていないキャラを外して、持っているキャラだけで提案させることもできます

【読めないときは、読めないと言う】
・ドラフト画面だと確認できない画像は解析しません
・ステージ名が読めないときは推測で答えず、自分で選べるようにしています

【プライバシー】
・スクリーンショットの解析は端末内だけで行い、画像を外へ送りません
・アカウント登録・広告・追跡はありません

本アプリは非公式のファンツールで、Supercell 社とは関係ありません。
利用規約: https://asanoitsuki.github.io/brawl-stars-draft-ai/terms.html
```

## このバージョンの新機能
```
スクショ解析に特化して作り直しました。
・BAN ありの新しいドラフト画面に対応（BAN の番とピックの番を判定）
・背面タップの設定手順をアプリ内に追加
・通知で提案キャラ 3 体を表示
・ドラフト画面ではない画像は解析しないように
・チーム募集・プロフィール・チャットの機能を終了
```

## 審査メモ
```
【サインイン】不要です。アカウント作成はありません。

【確認手順】
1. ホームの「写真から選ぶ」（右の画像ボタン）で、ガチバトルのドラフト画面（横向き）のスクリーンショットを選ぶと、ステージと BAN／ピックの番を読み取り、おすすめのキャラを表示します。
2. ドラフト画面ではない画像（風景写真など）を選ぶと「ドラフト画面だと確認できませんでした」と表示され、解析しません。
3. 「背面タップで解析できるようにする」で、ショートカットと背面タップの設定手順を確認できます。
4. 「マップ」「キャラ」で、ステージ別の実測勝率を見られます。

【前回の 4.1(a) への対応】ゲームの画像（キャラ・マップ・ランクのアイコン）はアプリに含めていません。表示はすべて自作です（キャラは頭文字の色付きアイコン、マップは格子のサムネイル）。ゲーム内の名前は、データを説明するための文字として表示しています。

【外部サービス】Brawl Stars 公式 API の対戦記録を開発者側で集計したデータ（GitHub から取得）。画像の解析は端末内だけで行い、外へ送りません。広告・分析・トラッキングはありません。

本アプリは無料・広告なしの非公式ファンツールで、Supercell 社とは関係ありません。
```
