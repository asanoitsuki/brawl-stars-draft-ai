# App Store 提出ガイド — Brawl Board

App Store Connect にそのまま貼れる文面と、提出前にあなたがやること（チェックリスト）です。
アプリ側の対応（プライバシーマニフェスト・データ削除・通報/ブロック・規約同意など）は実装済みです。

## 0. 提出前にあなたがやること（コードでは解決できないもの）

| # | やること | 理由 |
|---|---|---|
| 1 | **バンドルIDを自分のものに変える**（`com.example.brawldraftai` → 例 `jp.itsuki.brawlboard`） | `com.example.*` は誰でも使える仮の名前で、App Store には出せない。変えると iCloud コンテナも `iCloud.<新ID>` になる |
| 2 | **新しいコンテナにスキーマを登録して本番へ反映**（下の手順） | 本番（App Store/TestFlight）は CloudKit の「本番環境」を使う。開発環境のままだと一覧が読めない |
| 3 | **連絡先メールを決める**（任意だが推奨） | 今はサポート窓口が GitHub Issues のみ。App Review が連絡できる窓口として、App Store Connect の「連絡先」にはメールか電話が必須 |
| 4 | **Vercel のプロフィール取得サーバーを動かす**（`brawl-board-api` は作成済み・動作確認済み） | 無いと「プロフィール自動作成」がスクショ読み取りだけになる |
| 5 | **Supercell に確認する**（任意・推奨。下の「知的財産」） | ゲームの画像・名前を使うため |
| 6 | App Store Connect で **「Appのプライバシー」を下の通りに回答** | `PrivacyInfo.xcprivacy` と同じ内容 |
| 7 | **年齢レーティングの質問票に回答**（下の目安） | チャット（ユーザー作成コンテンツ）があるため |
| 8 | スクリーンショットを登録（`appstore/screenshots/`、1320×2868 = 6.9インチ） | iPhone のみ対応。iPad は v1.0 では非対応にしてある |

### 手順 2: CloudKit を本番へ
```bash
# 新しいバンドルIDに変えたあと、Xcode の署名で iCloud コンテナを作る（初回ビルドで自動）
cd ios/BrawlDraftAI
$(xcrun --find cktool) import-schema --team-id <チームID> --container-id iCloud.<新バンドルID> \
  --environment development --file CloudKit/schema.ckdb
```
その後 https://icloud.developer.apple.com/ → 該当コンテナ → **Deploy Schema Changes…（Development → Production）**。

## 2. Appのプライバシー（App Store Connect の回答）

**「データを収集していますか？」→ はい**（プロフィール・募集・チャットを使ったときに、iCloud の公開データベースへ保存するため）

| データの種類 | 収集 | ユーザーに紐づく | トラッキングに使用 | 利用目的 |

| 連絡先情報 > **名前**（ゲーム内の名前・表示名） | はい | はい | いいえ | Appの機能 |
| 識別子 > **ユーザID**（iCloud の匿名ID） | はい | はい | いいえ | Appの機能 |
| ユーザコンテンツ > **その他のユーザコンテンツ**（プロフィール・募集・チャット・ひとこと） | はい | はい | いいえ | Appの機能 |
| 写真またはビデオ | **いいえ**（端末内で解析、外部送信なし） | — | — | — |
| 使用状況データ・診断・位置情報・連絡先・購入 | いいえ | — | — | — |

**トラッキング：なし。** 「Appのトラッキング」は「いいえ」。広告SDK・分析SDKは使っていません。

## 3. 年齢レーティングの目安

質問票への回答（実態どおり）:
- ユーザーが作成するコンテンツ／チャット: **あり**（募集・チャット。通報・ブロック・フィルタあり）
- 暴力・性的内容・ギャンブル・薬物・ホラー: **なし**（アプリ自体には無し。ゲームの名前に触れるのみ）
- 制限なしのWebアクセス: **なし**（Discord・ブロスタへのリンクは外部アプリを開くだけ）

→ ユーザー作成コンテンツ／チャットを「あり」にするため、**12+ 以上**になる想定です。質問票の結果をそのまま採用してください。

## 4. App Review 向けメモ（「審査に関する情報」→ メモ欄にそのまま貼る）

```
【サインイン】不要です。アカウント作成はありません。

【確認手順】
1. ホームの「マップ」「キャラ」で、ガチバトルの実戦データ（勝率・使用率）が見られます。
2. 「チーム募集」を開くと、最初にプロフィール作成画面が出ます。
   ・「先に募集を見る」で一覧だけ見られます。
   ・プロフィール作成は、プレイヤータグの入力（例: #2PP0Y8LQ）か、プロフィール画面のスクリーンショット選択で行います。
   ・プレイヤータグは Brawl Stars の公開プロフィールで、Supercell 社の公式 API から取得します。
     公式 API がメンテナンス中は「メンテナンス中」と表示されます（アプリの不具合ではありません）。
3. 投稿・チャット・プロフィールの公開には iCloud へのサインインが必要です（見るだけならサインイン不要）。

【ユーザー作成コンテンツ（ガイドライン 1.2）への対応】
・禁止内容を定めた利用規約。初めて投稿・チャットする前に同意を求めます（同意しないと送信できません）
・NG ワードの自動フィルタ（投稿・チャット・プロフィール）

【外部サービス】Brawl Stars 公式 API（プロフィール取得、開発者の中継サーバー経由・保存なし）、Brawlify（画像表示）、

【権利】Supercell 社の非公式ファンツールです（無料・広告なし。ファンコンテンツポリシーの範囲）。
アプリのアイコン・ロゴは自作で、ゲームのキャラクター画像は使っていません。

【連絡先】<ここにメールアドレスを書く>
```

## 5. 知的財産（リスクと対策）— 正直な評価

| 項目 | 状態 | リスク |
|---|---|---|
| アプリアイコン・ロゴ | **自作**（宇宙の球＋「B」）。ゲームのキャラは不使用 | 低 |
| アプリ名「Brawl Board」 | 「Brawl」を含む | **中**。Supercell の商標「Brawl Stars」と紛らわしいと指摘される可能性。心配なら `Board for Brawlers` など「Brawl」単独を避けた名前も検討 |
| ブロウラーのアイコン・マップ画像（アプリ内表示） | Brawlify 経由で取得した Supercell 社の画像を表示 | **中**。ファンコンテンツポリシーは「無料・非商用・非公式の明示」を条件に許容。有料化・広告・課金を入れたら不可 |
| 説明文・キーワードの「ブロスタ / Brawl Stars」 | 商標の記述的使用 | 低〜中 |

**推奨**: Supercell のファンコンテンツ窓口（https://supercell.com/en/fan-content-policy/ に記載）へ、アプリの概要を送って**書面で確認**を取ってください。
審査でガイドライン 5.2（知的財産）を指摘された場合の返信材料になります。
審査で画像の使用が問題になった場合は、ブロウラー画像をテキスト表示にする対応が可能です（言ってもらえればやります）。
